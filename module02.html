供应商 / 货源中心

Module 02负责维护供应商与实际货源。 供应商与货源通过 supplierId 建立关系， 每条货源通过唯一 sourceId 作为 Module 03 的匹配数据接口。

模块数据关系

固定数据关系： 供应商 Supplier → supplierId → 货源 Source → sourceId → Module 03 商机匹配

Module 02 不创建客户需求。 客户具体需求来自 Module 01。 Module 03 将读取 Module 01 的 Demand， 再读取本模块 Source， 按照原料、规格、产地、数量、状态、交付等条件形成一对多匹配。

🧪 Module 02 自动化测试

自动测试会在当前 Module 02 数据库中建立临时供应商和临时货源， 验证：
① Supplier 创建
② Supplier 查询
③ Supplier 编辑
④ Source 创建
⑤ Source 查询
⑥ Source 编辑
⑦ supplierId 关联
⑧ sourceId 唯一性
⑨ Module 03 可读取 Source
⑩ 测试结束后恢复测试前正式数据

测试不会修改 Module 01 数据。 测试产生的临时 Supplier / Source 会自动清除。
