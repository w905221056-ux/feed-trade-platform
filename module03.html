商机匹配 / 交易撮合中心

Module 03 不创建客户需求，也不创建供应商货源。 系统只读取 Module 01 的 Demand 与 Module 02 的 Source， 按照匹配规则形成商机候选，并在 Module 03 内记录人工确认结果。

数据边界： Module 01 和 Module 02 是上游正式业务数据。 Module 03 对两者只执行读取，不执行新增、编辑、删除或覆盖。 Module 03 自己产生的 matchId / 商机状态 / 跟进备注 仅保存于 Module 03 自己的数据库。

匹配规则说明

一级核心条件 原料名称
原料不一致时，不形成有效匹配。
二级条件 规格
有明确规格时进行规格兼容判断。
数量 需求量 / 可供量
货源数量不足时降低匹配等级，不直接改变货源数量。
交付条件 到货地
需求与货源到货地一致或可兼容时加分。
产地 产地兼容性
需求明确指定产地时进行判断。
状态 Source有效状态
暂停、关闭等状态不形成有效商机。

重要： “匹配评分”只是系统判断结果， 不是成交价格、不是合同价格、不是订单价格，也不是自动成交。 真正的成交必须经过人工业务确认。
