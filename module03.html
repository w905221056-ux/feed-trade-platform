商机匹配中心

Module 03 不创建客户需求，也不创建货源。 本模块只读取 Module 01 的 Demand 与 Module 02 的 Source， 根据原料、规格、产地、数量、到货地、付款方式、有效期及状态进行实时匹配。

模块数据连接

匹配规则

① 原料：硬条件 原料名称经过标准化处理后必须一致。 原料不一致，不进入有效匹配。
② 货源状态：硬条件 货源状态为暂停、关闭或无法识别为有效状态时， 不进入有效匹配。
③ 有效期：硬条件 存在有效期且已经过期的 Source， 不进入有效匹配。
④ 数量：硬条件 Source 可供数量必须大于或等于 Demand 数量， 才可判定为数量满足。
⑤ 规格 / 产地 / 到货地 Demand 有明确要求时， Source 对应字段一致则提高匹配度； 明确冲突则降低匹配度。
⑥ 付款方式 Demand 有付款方式要求时， Source 相同则提高匹配度。 无明确要求不作为否决条件。

Module 03原则：

1. 不复制 Demand 数据作为独立数据库
2. 不复制 Source 数据作为独立数据库
3. 不修改 Module 01
4. 不修改 Module 02
5. 每次重新匹配时重新读取最新数据
6. Demand / Source 的原始 ID 永远保持原值
7. 匹配结果属于计算结果，不作为业务主数据保存
