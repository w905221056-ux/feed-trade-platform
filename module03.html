匹配引擎

匹配不是简单的 ID 关联。 系统按：
原料 → 规格 → 交货地 → 产地 → 交货期 → 付款方式 → 数量 → 价格 → 货源状态
逐项判断，并允许数量不足形成“部分匹配”。
选择一个需求查看可匹配货源。
