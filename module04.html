交易管理中心

Module 04负责将 Module 03 的商机匹配结果转化为正式交易业务。 本模块不修改 Module 01 / Module 02 / Module 03 原始数据。 交易数据按照 Opportunity → Quote → Deal → Sales Contract → Purchase Contract → Trade Order 建立完整追溯关系。

Module 04 交易流程

① 商机 Opportunity
② 报价 Quote
③ 成交 Deal
④ 销售合同 Sales Contract
⑤ 采购合同 Purchase Contract
⑥ 交易订单 Trade Order
业务原则： 前一阶段必须完成后才能进入后一阶段。 报价未确认不能形成成交；成交未确认不能建立正式合同；销售合同与采购合同分别管理；交易订单必须同时具备有效销售合同和采购合同。

Module 04 原则：

1. 不修改 Module 01 Demand
2. 不修改 Module 02 Source
3. 不修改 Module 03 匹配结果
4. Opportunity保存交易启动时的引用关系
5. Demand / Source 原始ID保持不变
6. 每种业务对象拥有独立唯一ID
7. 销售价格与采购价格独立保存
8. 毛利根据成交交易价格计算
9. 前置业务状态不能绕过流程直接进入后置业务
10. 后续资金 / 物流 / 结算模块读取 TradeOrder
